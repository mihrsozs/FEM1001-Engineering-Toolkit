# FEM1001 Engineering Toolkit

Herramientas, notebooks y desarrollos computacionales para la aplicación de **FEM 1.001 — Rules for the Design of Hoisting Appliances**, con foco en el análisis estructural de equipos de izaje.

El repositorio reúne desarrollos teóricos y computacionales organizados por Booklet, integrando:

- interpretación normativa;
- formulación matemática;
- implementación en Python;
- tablas y gráficos;
- criterios de modelación estructural;
- verificación de cargas y solicitaciones.
